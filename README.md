## 📱 About the Project

**Finance App** is a personal finance management tool designed to help users effortlessly monitor their financial activities. With an intuitive interface and powerful features, it provides real-time insights into your spending habits, helping you make smarter financial decisions.

Whether you're a student, freelancer, or family manager, this app gives you full control over your money in a simple and elegant way.

## ✨ Key Features

- **Modern Dashboard** — Overview of current balance, total income, and total expenses
- **Add & Edit Transactions** — Title, amount, type (Income/Expense), category, date, and notes
- **Smart Transaction List** — Search, filter by type, swipe to delete, and click to edit
- **Powerful Reports** — Interactive Pie Chart (expenses by category) and Bar Chart
- **Multi-Currency Support** — ILS, USD, JOD, EUR
- **Dark Mode** — Full support for light and dark themes
- **Offline First** — All data stored locally using Room Database

## 🛠 Tech Stack

- **Language**: Java
- **Architecture**: MVVM (Model-View-ViewModel)
- **UI**: Material Design 3 + Data Binding
- **Database**: Room + DAO
- **Charts**: MPAndroidChart
- **Asynchronous**: LiveData + Coroutines (via ExecutorService)
- **Dependency Injection**: Manual (can be extended with Hilt)
- **RecyclerView** with ItemTouchHelper for swipe actions
